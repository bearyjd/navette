ARCHITECTURE NOTE WORTH CARRYING
  navette-bridge is a LIBRARY, not a process. navetted links it and owns the
  calloop event loop, so there is no IPC hop between them. This is easy to
  misread from the crate names alone and it changes where code can live: for
  example clipboard handling cannot go in scene.rs, because scene.apply()
  returns events and holds no transport.
